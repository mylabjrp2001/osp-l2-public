# DMP Monthly Report (BKK)

เว็บรายงานประจำเดือนของ **DMP Advance Solution Network (BKK)** แปลงมาจากรายงาน Power BI เดิม
อ่านไฟล์ Excel งานซ่อม แล้วสร้างรายงาน 21 หน้า (ตรงกับ PDF หน้า 2–22) พร้อม Dashboard หลังบ้าน
กรองตามช่วงวันที่ / โซน / ทีม / Priority ได้ทุกหน้า และ export เป็น PDF หรือ PowerPoint ได้

โปรแกรมรันบนเครื่องของคุณเอง ไม่ต้องต่อเซิร์ฟเวอร์ที่ไหน

---

## ติดตั้งและใช้งานบน Windows

### 1. ติดตั้ง 2 โปรแกรมนี้ก่อน (ทำครั้งเดียว)

| โปรแกรม | ลิงก์ | หมายเหตุ |
|---|---|---|
| **Python 3.12** | https://www.python.org/downloads/windows/ | ตอนติดตั้ง **ต้องติ๊ก ☑ Add python.exe to PATH** ที่หน้าแรก |
| **Node.js LTS** | https://nodejs.org/ | กด Next ไปเรื่อย ๆ ตามค่าเริ่มต้น |

ติดตั้งเสร็จแล้ว **ปิดหน้าต่าง Command Prompt ที่เปิดค้างไว้ทั้งหมด** แล้วเปิดใหม่ (เพื่อให้เห็น PATH ใหม่)

### 2. ดาวน์โหลดโค้ด

ถ้ามี Git:
```
git clone https://github.com/mylabjrp2001/osp-l2-public.git
```

ถ้าไม่มี Git: กดปุ่มเขียว **Code → Download ZIP** บนหน้า GitHub แล้วแตกไฟล์
(ถ้าโหลดมาเป็น ZIP ให้คลิกขวาที่ `start.bat` → **Properties** → ติ๊ก **Unblock** → OK ก่อนใช้ครั้งแรก
ไม่งั้น Windows อาจเตือน SmartScreen)

### 3. ดับเบิลคลิกไฟล์ในโฟลเดอร์ที่ได้มา

| ไฟล์ | ใช้ตอนไหน | เปิดที่ |
|---|---|---|
| **`start.bat`** | ใช้งานรายงานตามปกติ | http://localhost:8000 (เปิดเบราว์เซอร์ให้อัตโนมัติ) |
| **`dev.bat`** | ตอนแก้โค้ด — แก้ไฟล์แล้วหน้าเว็บอัปเดตเอง | http://localhost:5173 |

- **ครั้งแรกจะใช้เวลาหลายนาที** เพราะต้องติดตั้งส่วนประกอบและสร้างข้อมูลจาก Excel ครั้งต่อไปเปิดในไม่กี่วินาที
- หน้าต่างสีดำจะขึ้นแบนเนอร์ **OSP L2** พร้อมสถานะ (Python / Node / จำนวนงาน / ที่อยู่เว็บ) แล้ว
  **ค้างไว้ไหล log ของเซิร์ฟเวอร์** ตลอดเวลาใช้งาน — **ห้ามปิด** ปิดเมื่อไหร่คือปิดโปรแกรม
- หยุดโปรแกรม: กด `Ctrl` + `C` หรือปิดหน้าต่าง · ถ้าเซิร์ฟเวอร์หยุดเองหรือเปิดไม่ติด หน้าต่างจะค้างให้อ่านสาเหตุ
  ต้องกด Enter ถึงจะปิด
- ถ้าเผลอดับเบิลคลิก `start.bat` ซ้ำตอนที่เปิดอยู่แล้ว มันจะแค่เปิดเบราว์เซอร์ให้ใหม่ ไม่เปิดเซิร์ฟเวอร์ซ้อน
- เปลี่ยนพอร์ต: เปิด `start.bat` ด้วย Notepad แล้วแก้บรรทัด `rem set "OSP_PORT=8010"` (ลบคำว่า `rem` ออก)

## การใช้งานประจำ

### อัปเดตข้อมูล

กดปุ่ม **📥 Upload Excel** มุมขวาบนของเว็บ แล้วเลือกไฟล์

- ชื่อไฟล์ต้องเป็น **`Data Job done <ปี>.xlsx`** หรือ `.xlsm` เช่น `Data Job done 2026.xlsx`
- อัปไฟล์ปีเดิม = แทนที่ของเดิม · อัปไฟล์ปีใหม่ = เพิ่มเข้าไป (รายงานรวมทุกปีที่มี)
- อัปเสร็จระบบจะประมวลผลใหม่ให้เองประมาณ 10–15 วินาที แล้วรายงานจะอัปเดตทันที
- ข้อมูลที่อัปจะอยู่ **ในเครื่องนี้เท่านั้น** ไม่ส่งไปที่ไหน

ข้อมูลตั้งต้นที่แถมมากับโค้ดคือไฟล์ในโฟลเดอร์ `Excel Data/` (ข้อมูลถึง 13 ก.ย. 2026)
จะถูกคัดลอกไปใช้ในครั้งแรกที่รันครั้งเดียว

**อยากกลับไปใช้ข้อมูลตั้งต้นใหม่:** ลบโฟลเดอร์ `dmp-monthly-report\server\storage` ทิ้ง แล้วดับเบิลคลิก `start.bat` อีกครั้ง

### Export รายงาน

- **PDF** / **PowerPoint** — ได้ 21 หน้ารายงาน (ไม่รวมหน้า Dashboard หลังบ้าน) ใช้เวลาประมาณ 30 วินาที อย่าปิดหน้าเว็บระหว่างนั้น
- **Present** — โหมดเต็มจอสำหรับนำเสนอ กด `←` `→` เปลี่ยนหน้า กด `Esc` ออก

### บันทึกใต้กราฟ (Problem and Solution)

ช่องพิมพ์บันทึกในหน้า Overview ของแต่ละทีม **เก็บไว้ในเบราว์เซอร์ของเครื่องนั้น** ไม่ได้เก็บบนเซิร์ฟเวอร์
เปลี่ยนเครื่องหรือล้างข้อมูลเบราว์เซอร์แล้วบันทึกจะหาย

## เจอปัญหา ทำยังไง

| อาการ | วิธีแก้ |
|---|---|
| ขึ้น `Python 3 was not found` | ยังไม่ได้ลง Python หรือลงแล้วไม่ได้ติ๊ก *Add python.exe to PATH* → ลงใหม่แล้วติ๊ก |
| ขึ้น `Node.js was not found` | ลง Node.js LTS จาก nodejs.org แล้วเปิด `start.bat` ใหม่ |
| ขึ้น `Port 8000 is used by another program` | มีโปรแกรมอื่นใช้พอร์ตนี้อยู่ · ปิดโปรแกรมนั้น หรือแก้ `rem set "OSP_PORT=8010"` ใน `start.bat` |
| หน้าต่างดำหายไปเอง | ไม่ควรเกิดแล้ว หน้าต่างถูกทำให้ค้างทุกกรณี ถ้ายังเจอ ถ่ายรูปข้อความสุดท้ายไว้แล้วแจ้งกลับ |
| เว็บเปิดมาแต่รายงานว่าง | ยังไม่มีข้อมูล — กด Upload Excel เพื่ออัปไฟล์ หรือเช็คว่าโฟลเดอร์ `Excel Data` มีไฟล์อยู่ |
| อัปไฟล์แล้วตัวเลขไม่เปลี่ยน | กด `Ctrl` + `F5` ที่หน้าเว็บ เพื่อโหลดข้อมูลใหม่ |
| Windows Firewall เด้งถาม (ตอนใช้ `dev.bat`) | กด Allow ได้ หรือจะกด Cancel ก็ยังใช้งานบนเครื่องตัวเองได้ปกติ |
| ตัวเลขเพี้ยนหลังอัปไฟล์ใหม่ | ดูว่าไฟล์ Excel มีคอลัมน์ครบตามเดิมไหม (ดู `COL_MAP` ใน [`server/etl.py`](dmp-monthly-report/server/etl.py)) ถ้าคอลัมน์ถูกเปลี่ยนชื่อ ระบบจะอ่านค่านั้นไม่เจอและปล่อยว่าง |

## สำหรับคนพัฒนาต่อ

อ่าน **[docs/developer-guide.md](docs/developer-guide.md)** — อธิบายว่าระบบประกอบด้วยอะไร Node กับ Python
ทำหน้าที่ต่างกันยังไง สูตรคำนวณแต่ละอย่างอยู่ไฟล์ไหน และกับดักที่เคยเจอมาแล้ว

รันบน macOS / Linux:
```bash
cd dmp-monthly-report
npm install
python3 -m venv server/.venv && server/.venv/bin/pip install -r server/requirements.txt
npm run dev:all          # เว็บ http://localhost:5173 + API http://localhost:8000
```

หรือรันด้วย Docker (ไม่ต้องลง Python/Node):
```bash
docker compose up -d --build dmp-report     # http://localhost:8000
```

**ข้อควรรู้ด้านความปลอดภัย:** แอปนี้ออกแบบมาให้รันบนเครื่องตัวเอง **ไม่มีระบบ login**
ใครเข้าถึงที่อยู่ของเว็บได้ก็อัปโหลดหรือลบไฟล์ข้อมูลได้ ถ้าจะเอาไปวางบนเซิร์ฟเวอร์ที่คนอื่นเข้าถึงได้
ต้องเพิ่มการยืนยันตัวตนไว้ข้างหน้าเอง
